# Task Manager
Sistema de gerenciamento de projetos e tarefas desenvolvido com Spring Boot e React.

## Tecnologias utilizadas
### Backend
- Java 21 
- Spring Boot 3.5.6
- Spring Security + JWT
- Spring Data JPA
- H2 Database
- JUnit + Mockito

### Frontend
- React 19.2.8
- Vite
- Material UI
- Axios
